Front-end Development is the Worst

Front-end development deals with the aspct of webdesign that users see. It's the functionality built initially on divs and spans, CSS specifies 'How' the site is served -It's like, "Oh, I want this to be blue, but not that blue."

Real programmers code, doing the backend of websites. They code on Arch Linux, not macOS, and certainly not Windows. They use Vim, not VS Code. They use C, not HTML. Come to the backend, where the real programming happens.
